## Read this first

The LMS has most of the right features, but some are broken, some are not switched on, and some show wrong or fake information.

This document lists 29 fixes. Each one says: what is wrong, why it matters, what to do, and how to check it is fixed.

Start at the top. Fixes CA-01 and CA-02 are a data leak and must be fixed today.

• A fix is only done when someone else has checked it, using the "How to check" line.

Each fix keeps its number (CA-01 to CA-29) so everyone talks about the same thing.

## Final check before WABON looks

1 Open the public API with no login: no user data, no answers, no files.

2 Make a brand-new test student and go through every page: locks work, agreement is complete, nothing fake shows.

3 Log in as the instructor and the admin: grading, feedback, attendance, skills check-offs, clinical sign-off and certificates work.

4 Log in as the WABON reviewer: both student and instructor screens are visible.

5 Go through the 19 rules above: each one is met, with a screenshot saved.

Screenshots to save for the application: course map, one full unit, a graded discussion, gradebook, Skills Lab, clinical log, exam ID check, week-one assignment, orientation attendance, schedule. Exports: crosswalk, gradebook, hours report.
